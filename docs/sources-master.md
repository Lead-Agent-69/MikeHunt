# MikeHunt sources: master list

Every vehicle data source MikeHunt has worked on, researched or discussed in the last ~48h (2026-10-08 to 2026-10-10 CT), one row each. Built 2026-10-10 from: the code registries on `main` (`lib/scrapers/runner.ts`, `sources-registry.ts`, `curated-sites.ts`, `lib/multisite`), every open and recently closed source PR (#214/#259, #221/#258, #231, #247, #249, #250, #252, #217's `docs/source-access-matrix.md`), the box audits (`salvage_sources.md`, `competitor_parity.md`, `open_gov_vehicle_data.md`, `dealer_network.json`, `sources.csv`, the platform sweep in `salvage-hunt/`), and the robots/terms evidence saved with them.

**Rule: never remove a source.** Sources whose terms ban automation stay registered as opt-in or deep links. Nothing in this PR runs on Zeus until an operator wires it (section 7).

## 6. What couldn't be added, and why

- **Terms-banned marketplaces stay opt-in or deep link, never default-swept:** Cars.com, Autotrader, AutoTempest, Carvana, CarGurus, Craigslist, eBay (scraping), Copart, PublicSurplus, Municibid, OfferUp, GovDeals, AllSurplus, CarParts.com. The licensed paths are registered: eBay Browse API, GSA official API, Auto.dev, MarketCheck (all need a free key).
- **Gated (login or dealer license):** IAA, ACV, ADESA/OPENLANE, Manheim, Facebook Marketplace scraping. Registered, `enabled:false`.
- **Rotating proxies, mobile-app API reverse-engineering:** not used (gets around site protections on purpose; risks banning Zeus).
- **Dealer Car Search / LeadVenture sites** (STS/asalvagecar CO 147, Sperry KY, 25 Auto MO, Midway MO, Zara CO, Ken's ND, Superior MI, Best Western AZ), ProSalvage MO, Sam's Riverside IA, Auto Gator CA, Rebuildables, Brickyard: terms ban or restrict reuse. Already registered on main and blocked by `source-compliance.ts`, not removed.
- **Visor and Carvana deep links:** left out. #273 excludes them: Visor is a competitor whose API terms bar competitive use, and Carvana ignores most link filters. Carvana stays registered as a runner source.
- **Memphis impound PDF:** registered; needs OCR (tesseract) on Zeus first.
- **Boston lots:** no VINs, so they can't dedupe or decode; registered as auction-day leads.
