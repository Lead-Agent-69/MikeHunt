## 🚨 What Could Go Wrong

| Risk                       | Mitigation                                                       |
| -------------------------- | ---------------------------------------------------------------- |
| Dealers don't log outcomes | Reminder notifications, gamification, show comparison            |
| Free users never upgrade   | Hard limits (3 alerts), show Pro features with "Upgrade" prompts |
| Geocoding too slow         | Normal. 1 req/sec is free. After 30 days, 90%+ geocoded          |
| Price snapshots fail       | Monitor pg_cron job daily, add alerts if >48h old                |
| Calibration overfits       | Limit to last 30 outcomes, exclude outliers >3σ                  |
